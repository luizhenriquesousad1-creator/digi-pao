# DigiPão - A padaria digital
Sistema web de vendas e gerenciamento de uma paradia, desenvolvido como atividade avaliativa da dsiciplina de 
Programação Backend.

## Objetivo
Desenvolver uma aplicação web que permite aos clientes consultar produtos e realizar pedidos online, enquanto 
a equipe administrativa gerencia produtos, estoque e vendas.

## Tecnologias utilizadas
- Python
- Django
- MySQL
- CSS3
- Bootstrap
- JavaScript
- Git e GitHub

## Funcionalidades Previstas

### Área do Cliente
- Cadastro e autenticação
- Catálogo de produtos
- Carrinho de compras
- Realização de pedidos
- Retirada na padaria ou entrega
- Histórico de pedidos

### Área administrativo
- Gerenciamento de produtos
- Gerenciamento de categorias
- Controle de estoque
- Gerenciamento de pedidos
- Painel administrativo
